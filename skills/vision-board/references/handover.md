# Handover

For a card the person moved to Later: you owe a `park` handover, which a new chat can pick up
without this conversation.

- Write `park { n, bundle }`, the `bundle` holding `situation`, `background`, `assessment` and
  `recommendation`, and `sources`, a list of the files and links it rests on. Name the card numbers it
  depends on in its text.
- The card shows it as its **Handover** section, each part as Markdown: write each part short, in
  whatever form reads best (a line, bullets, a small table).
- Give it a key like any item (`pricing-park-n6`). If the person takes the card out of Later and
  saves it again, a fresh handover is owed: a new `park` with what is known now, under a new key,
  never a copy of the old one.
- A `park` answers the Later only; a note on the same card still needs its `reply`.
