How each mark in the plate and each half of the switch answers the keyboard and the pointer; right-click; the "N updates" stepper inside history; the conversation box in this skin, with a note queued for Send and one asked now; and an icon an agent added.

Keyboard focusThe node is one tab stop; its ring sits outside the border, so it never reads as selection. Tab goes on through the plate in reading order (number, history, notes), then the two halves. The plate is not a tab stop: Alt+Arrows move the focused node. On the dark plate the ring is light.

The conversation: a note queued, and one asked nowThe notes button opens one box beside the node, in this skin's look: the plate's dark header with the number and title. Add note (Enter) queues the note for the board's Send, as today; Ask now (Cmd Enter) sends this one message for this node at once, and the agent answers in the box. How much of the board the agent sees is not decided, so nothing here says.
