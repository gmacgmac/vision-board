# The chat sends each note once

> **Follows**: `2026-10-11_board-agent_chat-board-context.md` (committed `007c11f`) · **From**:
> maintainer, 2026-10-11 ("we should definitely not do that … it affects context") · **Model**:
> Sonnet 5.5 · **Go**: given

## Problem

An unsent note goes to the agent twice: the composer auto-adds every unsent note as a chip
(`apps/board/src/board/chat-bridge.ts` `unsentNotes`, `composerChips`), so the prompt lists it under
"Attached from the board:" (`apps/board/server/chat-prompt.ts` `promptFor`), and the same note is one
of the answers in the Send block (`chat-round.ts` `roundText`, `replyScope`). The answers chip
("N answers since your last Send") already shows it.

## Rulings (maintainer; do not reopen)

1. The answers are the board's context; a note that is one of them is sent once, in the answers.
2. The composer no longer auto-adds unsent notes as chips (the answers chip covers them); selected
   cards stay as chips.
3. The server never lists a note under "Attached" when the same message's answers include it (a
   page or an older client may still send it): it drops the note line and its chip there.
4. A card that is selected AND answered stays under "Attached" as `- Card n: title` (a selection is
   the person pointing at it), but nothing about its answer repeats there.
